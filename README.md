# Cost calculator — Syrian Data Platform

A one-page calculator for the monthly running cost of the platform: database, Google Cloud services and AI.

Open it here: https://meik19998shaar.github.io/sdp-cost-calculator/

- Enter the number of registered users, the share of users who visit each day, and the AI question limit per user per month.
- The page shows the measured values at the top and lists every value that is not measured at the bottom.
- It is one HTML file with no outside libraries. It works offline.
